# security review

Read security context and current relevant source. Trace untrusted input to database, network and presentation boundaries. Check owner/member restrictions, job access, audit paths and rate limits. Keep sensitive contents out of reports. Distinguish exploitable findings from unverified concerns. Do not probe live services without task authorization.

Shared policy: read AGENTS.md from the repository root. Commands and evidence: docs/operations/agent-workflow.md.
