# Glossary

| Term         | Meaning                                                                      |
| ------------ | ---------------------------------------------------------------------------- |
| Source       | Shared catalog entry collected through an allowlisted connector              |
| Monitor      | An account-owned rule used to select jobs                                    |
| Match        | Persisted relationship between a monitor and a job                           |
| JEV          | The only application model decision service; see the canonical JEV documents |
| Owner/member | Application access roles, independent of development task ownership          |
| Task owner   | Single implementation owner recorded in task state                           |
| Evidence     | Executed check outcomes tied to source hashes, not a proposed check          |
| Index        | Rebuildable navigation aid; source and Git remain authoritative              |
