# code review

Inspect current Git diff and source, not only summaries. Trace callers across changed boundaries. Check API responses, ownership isolation, transaction rollback/release and client/server imports. Report actionable findings with file/line evidence and test gaps. Do not silently implement fixes during a review-only task.

Shared policy: read AGENTS.md from the repository root. Commands and evidence: docs/operations/agent-workflow.md.
