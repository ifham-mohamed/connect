# change planning

Inspect Git and relevant source first. Create brief.md, plan.md, state.json, findings.md and verification.md under .agent/tasks/<id>. Record baseline HEAD and existing changes separately from intended edits. Order independent reviewable stages and define behavior checks. Use agent:changed-files for an observation, never as proof of authorship.

Shared policy: read AGENTS.md from the repository root. Commands and evidence: docs/operations/agent-workflow.md.
