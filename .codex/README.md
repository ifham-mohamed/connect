# Codex adapter

Project policy comes from AGENTS.md. Shared skills are generated in .agents/skills from .agent/skills; check drift before replacing local edits. The project config registers the local read-only MCP server with documentation-only implementer capabilities. Start Codex at the repository root; project trust and a new session may be needed. It does not override global model or permission settings. See [workflow](../docs/operations/agent-workflow.md).
